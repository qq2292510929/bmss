## 动态效果说明

### 1. 功率仪表盘动画
```
低功率 (0-1000W):
    颜色: 绿色 → 蓝色
    动画: 平缓脉冲 (2秒周期)
    特效: 无

中功率 (1000-2500W):
    颜色: 绿色 → 黄色
    动画: 中速脉冲 (1.5秒周期)
    特效: 轻微发光

高功率 (2500-4000W):
    颜色: 黄色 → 橙色 → 红色
    动画: 快速脉冲 (1秒周期)
    特效: 发光 + 边框脉冲

战斗功率 (4000W+):
    颜色: 红色 → 白色
    动画: 高速脉冲 (0.5秒周期)
    特效: 粒子火花 + 全屏边框呼吸
```

### 2. 颜色渐变示例

#### 放电状态
```
功率变化时:
    0W    →  绿色 #07E0    (节能模式)
    1000W →  黄色 #FFE0    (普通模式)
    2000W →  橙色 #FBE0    (运动模式)
    3000W →  红色 #F800    (战斗模式)
    5000W →  白色 #FFFF    (极限模式)
```

#### 充电状态
```
充电时显示:
    🔌 充电中 (绿色文字)
    功率显示变为负数
    仪表盘颜色变为蓝色系列
```

### 3. 卡片动画

#### 连接状态
```
已连接:
    右上角蓝牙图标: 绿色脉冲
    显示文字: "已连接"
    每2秒闪烁一次

断开连接:
    右上角蓝牙图标: 红色静态
    显示文字: "未连接"
    整个界面变暗
```

#### 数据更新
```
数据到达时:
    数值文字: 轻微缩放动画
    进度条: 平滑过渡
    功率环: 颜色渐变动画
```

### 4. 特效层次

```
基础层:
    背景网格 (暗蓝灰色)
    
卡片层:
    主卡片 (深蓝色圆角矩形)
    阴影 (3px偏移黑色)
    高光 (左上角弧形)

数据层:
    数值文字 (白色)
    单位文字 (金色)
    状态标签 (彩色)

特效层:
    边框呼吸 (半透明脉冲)
    粒子效果 (高功率时)
    脉冲环 (充放电状态)
```

### 5. 文字显示

#### 主标题
```
文字: "⚡ 战斗模式 ⚡"
字体: NotoSans Bold, 16pt
颜色: 随功率变化 (绿色→白色)
动画: 轻微发光脉冲
```

#### 功率数字
```
文字: "1234" (根据实际功率)
字体: NotoSans Bold, 32pt
颜色: 功率对应色
动画: 数值变化时平滑过渡
```

#### 单位标签
```
文字: "W", "V", "A", "°C", "%"
字体: NotoSans Bold, 8-12pt
颜色: 金色或白色
位置: 紧邻数值
```

#### 状态文字
```
文字: "放电中", "充电中", "待机"
字体: NotoSans Bold, 12pt
颜色: 状态对应色
动画: 图标+文字脉冲
```

### 7. 交互效果

#### 开机动画
```
0.0s  黑屏
0.5s  背景网格淡入
1.0s  标题淡入
1.5s  主卡片依次显示
2.0s  功率数字开始跳动
2.5s  特效启动
3.0s  准备就绪
```

#### 数据刷新
```
每100ms更新一次
    1. 清除需要更新的区域
    2. 绘制新数据
    3. 应用动画效果
    4. 无闪烁 (区域刷新)
```
