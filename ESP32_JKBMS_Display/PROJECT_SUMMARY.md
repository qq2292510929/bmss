## 🚀 如何使用

### 编译和上传
```bash
cd ESP32_JKBMS_Display

# 编译
pio run

# 上传
pio run --target upload

# 打开串口监视器
pio device monitor
```

### 硬件连接
```
ESP32-32E      ST7789 2.8"
3.3V      ──── VCC
GND       ──── GND
GPIO15    ──── CS
GPIO2     ──── DC
GPIO4     ──── RST
GPIO23    ──── MOSI
GPIO18    ──── SCLK
GPIO21    ──── BL
```

### 配置修改
如需修改蓝牙设备信息，编辑 `src/main.cpp`:
```cpp
#define BT_DEVICE_NAME "JK_BD4A24S10P"
#define BT_MAC_ADDRESS "98:da:20:07:b9:00"
```
