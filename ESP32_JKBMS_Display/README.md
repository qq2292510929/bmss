# ESP32 JK BMS 显示系统 - 战斗模式

基于ESP32-32E和2.8寸ST7789屏幕的JK BMS蓝牙数据显示系统

## 硬件配置

### 开发板
- **型号**: ESP32-32E
- **蓝牙**: 内置BLE 4.2

### 显示屏
- **型号**: 2.8寸 ST7789P3
- **分辨率**: 240x320
- **接口**: SPI
- **引脚连接**:
  ```
  ESP32    ->    ST7789
  GPIO15   ->    CS
  GPIO2    ->    DC
  GPIO4    ->    RST
  GPIO23   ->    MOSI
  GPIO18   ->    SCLK
  GPIO21   ->    BL (背光)
  3.3V     ->    VCC
  GND      ->    GND
  ```

### JK BMS配置
- **设备名称**: JK_BD4A24S10P
- **MAC地址**: 98:da:20:07:b9:00
- **协议版本**: JK02_32S

## 功能特性

### 主界面功能
1. **实时放电功率** - 主视觉中心，突出显示
2. **电池容量** - 已用/总容量，百分比显示
3. **电池温度** - 双温度传感器显示
4. **电压/电流** - 实时数据监控
5. **蓝牙连接状态** - 右上角图标指示

### 战斗模式特点
- 🎨 **动态配色**: 功率越高，颜色越激烈
  - 低功率: 绿色 (节能)
  - 中功率: 黄色 (普通)
  - 高功率: 橙色 (运动)
  - 满功率: 红色 (战斗)

- ⚡ **动态效果**:
  - 功率环发光动画
  - 充放电状态脉冲
  - 边框呼吸灯效果
  - 粒子火花特效

- 🎯 **圆角卡片设计**:
  - 阴影层次感
  - 高光边缘
  - 平滑过渡

## 安装步骤

### 1. 安装PlatformIO

推荐使用PlatformIO IDE for VSCode:
- 下载安装 [VSCode](https://code.visualstudio.com/)
- 安装 PlatformIO IDE 插件
- 重启VSCode

或者使用命令行:
```bash
pip install platformio
```

### 2. 硬件连接

按照上面的引脚对照表连接ESP32和ST7789屏幕

### 3. 配置设备信息

编辑 `src/main.cpp` 中的以下配置:
```cpp
#define BT_DEVICE_NAME "JK_BD4A24S10P"
#define BT_MAC_ADDRESS "98:da:20:07:b9:00"
#define JK_PROTOCOL_VERSION "JK02_32S"
```

### 4. 上传程序

在PlatformIO终端中执行:
```bash
cd ESP32_JKBMS_Display
pio run --target upload
```

### 5. 监控输出

```bash
pio device monitor
```

波特率: 115200

## 使用说明

### 开机流程
1. 系统启动后自动初始化屏幕
2. 显示"初始化屏幕..."提示
3. 自动扫描并连接JK_BD4A24S10P
4. 连接成功后显示实时数据

### 界面解读

#### 顶部区域
- ⚡ 战斗模式标题 (颜色随功率变化)
- 🔵 蓝牙连接状态指示灯

#### 中央主区域
- **功率仪表盘**: 大号数字显示实时功率
- **圆环进度条**: 可视化功率水平
- **状态标签**: 放电/充电/待机

#### 中部区域
- **容量卡片**: 
  - 进度条显示剩余容量
  - 文字显示 Ah 数值
  - 百分比数字

#### 底部区域
- **温度卡片**: 两个温度传感器读数
- **电压电流**: 实时数据
- **SOC状态**: 电量百分比徽章
- **页脚**: 循环次数和电芯数

## 故障排除

### 蓝牙连接失败
1. 检查BMS是否开启蓝牙
2. 确认设备名称和MAC地址
3. 检查ESP32蓝牙天线
4. 尝试重启BMS和ESP32

### 屏幕不显示
1. 检查SPI接线
2. 确认CS/DC/RST引脚配置
3. 检查屏幕供电电压
4. 调整TFT_eSPI配置

### 数据不更新
1. 检查波特率设置(115200)
2. 确认协议版本匹配
3. 查看串口监视器错误信息
4. 检查蓝牙RSSI信号强度

## 技术细节

### 蓝牙协议
本项目实现了JK02协议的完整解析:
- 帧头识别: 0x4A 0x4B 0xFF 0x5A
- CRC校验
- 数据帧解析 (帧类型0x03)

### 显示优化
- 使用双缓冲减少闪烁
- 部分刷新节省资源
- 圆角优化算法
- 颜色插值平滑过渡

### 性能优化
- 独立蓝牙接收线程
- UI更新频率控制
- 避免频繁内存分配
- PSRAM内存利用
