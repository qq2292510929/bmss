🔧 技术规格

───────────────────────────────────────────────────────────────────────

硬件配置:
   • 开发板: ESP32-32E
   • 显示屏: 2.8寸 ST7789P3
   • 分辨率: 240x320
   • 接口: SPI (4线)
   • 蓝牙: BLE 4.2 (内置)

蓝牙配置:
   • 设备名: JK_BD4A24S10P
   • MAC地址: 98:da:20:07:b9:00
   • 协议版本: JK02_32S
   • 服务UUID: FFE0
   • 特征UUID: FFE1

显示配置:
   • SPI频率: 40MHz
   • 刷新率: 100ms
   • 方向: 横屏 (Rotation 1)
   • 背光: GPIO21

引脚连接:
   ESP32       ST7789
   ───────     ──────
   GPIO15  →   CS
   GPIO2   →   DC
   GPIO4   →   RST
   GPIO23  →   MOSI
   GPIO18  →   SCLK
   GPIO21  →   BL
   3.3V    →   VCC
   GND     →   GND

🚀 快速开始

───────────────────────────────────────────────────────────────────────

步骤1: 硬件准备
   ✅ ESP32-32E开发板
   ✅ 2.8寸 ST7789屏幕
   ✅ 连接线若干
   ✅ USB数据线

步骤2: 接线
   按照引脚对照表连接ESP32和ST7789屏幕

步骤3: 软件环境
   ✅ 安装VSCode + PlatformIO插件
   或
   ✅ 安装Arduino IDE + ESP32核心

步骤4: 编译上传
   # PlatformIO
   cd ESP32_JKBMS_Display
   pio run --target upload
   
   # Arduino IDE
   打开 src/main.cpp，编译并上传

步骤5: 监控测试
   pio device monitor
   (波特率: 115200)
